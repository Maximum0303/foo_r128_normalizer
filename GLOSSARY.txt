R128 リアルタイム音量ノーマライザー v1.12.0
用語集

このファイルは、設定画面の「用語集」と同じ内容を
公開・配布用に読みやすくまとめたものです。

────────────────────────────────────────
基本的な測定用語
────────────────────────────────────────

■ EBU R128
番組や音楽の聞こえる大きさをそろえるためのラウドネス測定方式です。
このコンポーネントはR128の考え方を基礎に、再生中の音量を
リアルタイムで調整します。

■ LUFS
人が感じる音の大きさを表す単位です。
値が0に近いほど大きく聞こえます。
例：-10 LUFSは-18 LUFSより大きな音量感です。

■ LU
ラウドネスの差を表す単位です。
1 LUの差は数値上1 dBの差に相当します。

■ Momentaryラウドネス
約400ミリ秒の短い区間で測ったラウドネスです。
瞬間的な音量変化を見る値です。

■ Short-termラウドネス
直近約3秒間のラウドネスです。
現在聞いている部分の音量感と、音量一致A/B比較に使用します。

■ Integratedラウドネス
測定開始から現在までをまとめた平均ラウドネスです。
入力Integratedラウドネスは処理前、出力Integratedラウドネスは処理後です。

■ ラウドネスレンジ（LRA）
Loudness Rangeの略です。
曲の静かな部分と大きな部分の幅、つまり抑揚の大きさを推定します。

■ True Peak / dBTP
デジタルサンプル間を補間して推定したピークです。
通常は-1.0 dBTP前後を上限にすると余裕を確保できます。

────────────────────────────────────────
設定と安全機能
────────────────────────────────────────

■ 目標ラウドネス
処理後に近づけたいラウドネスです。
0に近づけるほど音量感は増しますが、処理も強くなりやすくなります。

■ R128補正ゲイン最大増幅量 / 最大減衰量
R128補正ゲインが動ける範囲です。
極端な増幅や減衰を防ぐ安全上限です。

■ True Peakリミッター先読み時間
ピークが来る少し前にリミッターを動かすための時間です。
長くするとピークを抑えやすくなりますが、遅延も増えます。

■ True Peakリミッター解放時間
リミッターが音を抑えたあと、通常状態へ戻る速さです。

■ 曲頭安定化解析時間
曲の冒頭を測定し、増幅判断を安定させる時間です。
この間の「測定中・保留」は正常な安全動作です。

■ 静音保護 / 増幅保留
無音や非常に静かな区間を大きく増幅しないための機能です。

■ 補正ゲイン固定
ラウドネスが安定したあと、補正ゲインを一定に保ちます。
曲中の音量のふらつきを防ぎます。

■ リアルタイム自動制御
処理が強くなりすぎた際、全プリセットで最大6 dBまで安全側へ下げます。

■ 自動制御履歴
自動制御が実際に発動した曲を最新100件まで保存する一覧です。
再生日時、曲名／アーティスト、プリセット、発動理由、最大自動減衰量、
発動回数、調整上限、安全復帰を確認できます。
短い「監視中」だけで自動調整へ入らなかった曲は記録しません。

────────────────────────────────────────
音声処理
────────────────────────────────────────

■ コンプレッサー
大きすぎる部分だけを自動的に抑える処理です。

■ ソフトクリッパー
鋭いピークを滑らかに丸めて音量感を確保する処理です。
最大クリップは0 dBTP超過回数そのものではありません。

■ True Peakリミッター
最終段でTrue Peak上限を超えないように音量を抑えます。

■ モダンブースト
コンプレッサー、ソフトクリッパー、True Peakリミッターを
組み合わせた高密度モードです。

■ 1バンド・アダプティブ
入力ラウドネスやLRAを見ながら、処理強度を自動調整します。

■ 3バンド・アダプティブ
低域・中域・高域を分け、それぞれを別に制御します。
固定EQではありませんが、処理量によって音色は変化します。

再生中の「3バンド・アダプティブ減衰量」欄には現在の減衰量を表示します。
再生停止後は、前回トラックで各帯域が最も強く抑えられた量を
「前回 低／中／高」の形式で表示します。

■ クロスオーバー周波数
3バンド・アダプティブで帯域を分ける境界周波数です。
約160 Hzと約4 kHzを使用します。

────────────────────────────────────────
比較機能
────────────────────────────────────────

■ 音量一致A/B比較
処理前後のShort-termラウドネスを近づけて、
音量差ではなく音色や圧縮感を比較しやすくします。

■ 完全バイパス比較
「音量一致」を外して比較ボタンを押すと、
このコンポーネントの処理をすべて外します。
前段にある別のDSP処理は残ります。

────────────────────────────────────────
診断結果
────────────────────────────────────────

■ 最大True Peak
トラック中の処理後最大True Peakです。
+0.01 dBTPを超えた場合は要調整です。

■ 最大コンプレッサー減衰量
トラック中の最大コンプレッサー減衰量です。
6 dB以上は「強め」の目安です。

■ 最大ソフトクリッパー減衰量
トラック中の最大ソフトクリッパー整形量です。
3 dB以上は「要調整」です。

■ 最大True Peakリミッター減衰量
トラック中の最大リミッター減衰量です。
3 dB以上は「要調整」です。

■ 0 dBTP超過イベント
処理後のTrue Peakが0 dBTPを超えたイベント回数です。
通常は0回を想定しています。

■ CPU負荷
このDSPの推定処理負荷です。
総合評価の「安全／強め／要調整」には使用しません。

■ 現在の処理状態
再生中の処理負荷をリアルタイムで監視した状態です。

正常：現在の処理が安全範囲にあります。
監視中：過剰状態を検出し、0.75秒の継続確認中です。
自動調整中：内部の安全補正ゲインで正常範囲への復帰を進めています。
調整上限：最大6 dBの補正でも要調整相当が続いています。

安全な状態が3秒続くと補正をゆっくり解除し、正常へ戻ります。
発動理由はTrue Peak超過／リミッター過多／クリッパー過多／
複数要因で表示され、自動減衰量は正のdB値で表示されます。
未発動時は「この曲では未発動」、安全復帰後は
「直近：発動理由（復帰済み）」と表示されます。
過去の最大処理量は各最大値と0 dBTP超過イベントに残ります。

■ 異常値保護
デコーダーや前段DSPからNaN、無限値、極端な振幅が渡された場合に、
そのサンプルを安全な値へ置き換える保護機能です。

通常の有限な音声には作用しません。
作動回数は診断コピーの「異常値保護作動」で確認できます。
通常の再生では0サンプルになることを想定しています。


────────────────────────────────────────
設定画面のタブ
────────────────────────────────────────

■ 基本設定
目標ラウドネス、R128補正ゲイン最大増幅量・最大減衰量、True Peak上限、True Peakリミッター先読み時間、静音保護、
補正ゲイン固定など、R128ノーマライズの基本項目をまとめています。

■ 追加処理
モダン、1バンド・アダプティブ、3バンド・アダプティブを
まとめています。これらは音色やダイナミクスへ影響します。

■ 診断
再生中のラウドネス、ゲイン、ピーク処理、トラック最大値などを
まとめて確認できます。

プリセット、比較、適用ボタンはどのタブでも常に表示されます。


────────────────────────────────────────
ユーザープリセット
────────────────────────────────────────

現在の基本設定と追加処理設定を任意の名前で保存する機能です。
呼出、上書き、名前変更、削除に対応します。
既存7プリセットは変更されず、foobar2000の設定内へ別に保存されます。

補正モニター：7項目の意味
上から順に、次の値を表示します。約100ms更新です。

1. 入力 3秒（LUFS）
このDSPへ入った音の直近約3秒のラウドネスです。前段DSPの処理を含みます。ファイル全体の平均ではありません。

2. ゲイン（dB）
現在のR128ノーマライズによる補正ゲインです。＋は増幅、－は減衰、0は補正なしです。リミッター、自動保護、追加処理を合算した最終ゲインではありません。

3. 出力 3秒（LUFS）
このDSPが出力した音の直近約3秒のラウドネスです。後段DSPやプレーヤーの音量操作は含みません。入力との比較に使います。

4. True Peak（dBTP）
このDSPの出力ピークの近似値です。4倍補間・17タップで推定し、最近の表示区間の最大値を表示します。曲全体の最大値ではありません。0 dBTPはフルスケールの基準です。表示更新が遅れた場合、集計区間は長くなります。

5. リミッター（dB）
現在リミッターが抑えている量です。正の数値で表示します。例：2 dBは2 dBの減衰、0は減衰なしです。トラック最大値ではありません。

6. 自動保護（dB）
過度なピーク、リミッター、クリップ等を受け、自動保護が追加した現在の減衰量です。正の数値で表示し、0は追加減衰なしです。リミッターとは別の値です。詳細は診断・履歴を確認してください。

7. 適応強度（%／OFF）
Adaptiveが自動調整する、モダン処理の現在の実効強度です。音量の増加率や全R128処理の強さではありません。50%は音量が50%増える意味ではありません。無効時はオフ／OFFです。固定モダン処理の有効・無効を示す値でもありません。

補正モニター：単位とバー
LUFS：聴感に近いラウドネスの単位です。－18 LUFSは－23 LUFSより大きい値です。

dB：ゲインの変化量です。ゲイン欄は符号付き、リミッター・自動保護欄は正の減衰量です。

dBTP：フルスケールを基準にしたTrue Peakです。0 dBTPを超える場合はピーク設定や処理強度を確認します。

バーの範囲
入力／出力：－60～0 LUFS
ゲイン：絶対値0～24 dB（方向は数値の＋／－）
True Peak：－60～＋3 dBTP
リミッター／自動保護：0～12 dB
適応強度：0～100%

バーの両端を超える値は、バーだけ端で止まり、数値は実際の値を表示します。バーの満杯は音質・安全性の評価ではありません。目盛りは処理の上限や設定値を変更しません。

補正モニター：表示状態
動作中／Active：再生用のR128 DSPから現在の値を表示しています。

解析中／静音・Analyzing / silence：測定待ちや静音でラウドネスを表示できない状態です。再生開始後、3秒ラウドネスには約3秒の測定が必要です。約100ms更新は測定時間とは別です。

一時停止中／Paused・待機中／Waiting：一時停止や停止では現在値を隠します。再開後に更新されます。

—：現在値を確定できません。DSP未登録、複数登録、表示対象の曖昧さ、古い測定値等でも表示されます。無効なバーは0になります。数値の0やOFFとは意味が異なります。

原音比較中：入力だけを表示し、処理後の値は隠します。通常の処理へ戻ると出力測定も再開します。

変換用DSPの値は表示しません。モニターはfoobar2000 2.1以降が必要です。言語は本コンポーネントの「自動（Windows）／日本語／English」に追従します。

補正モニター：読み方とDSP順序
まず状態を確認し、入力と出力の3秒ラウドネス、ゲインの符号、True Peak、2種類の減衰量、適応強度の順に見ます。出力値が常に目標値と一致するとは限りません。音源・測定窓・ゲイン上限・追加処理・保護等の影響を受けます。

True Peakが高い状態や大きな減衰が続く場合は、診断・履歴も確認し、設定を見直す材料にしてください。瞬間値だけで音質の良し悪しは判断できません。

例：Sonic Refiner → R128 → 出力
R128の入力値はSonic Refiner処理後の音です。R128の出力値はR128処理後の音です。後段DSPやプレーヤー音量による変化は含みません。モニター間の数値は測定方法・表示区間が異なるため、単純に加算できません。

開く：Playback → R128 補正モニター
右クリック → モニターの見方...：この解説を開きます。
右クリック → 常に手前に表示：最前面を切り替えます。
位置・開閉状態・最前面設定を保存します。開いたままfoobar2000を終了すると次回起動時に再表示します。手動で閉じた場合は再表示しません。

この窓は表示用です。開く・閉じる・解説を読む操作でDSPの音声設定を変更しません。
