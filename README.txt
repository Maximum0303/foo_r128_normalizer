R128 リアルタイム音量ノーマライザー v1.10.0

通常の利用にVisual Studioやfoobar2000 SDKは必要ありません。

インストール:
1. foo_r128_normalizer_v1.10.0.fb2k-componentを開く
2. foobar2000へインストール
3. foobar2000を再起動
4. DSP Managerで「R128 音量ノーマライザー」を追加
5. 最初は「ナチュラル -18」を選択

設定画面を直接開く:
Playback → R128 音量ノーマライザーの設定...

DSPへ追加した後は、DSP Managerを経由せず設定画面を開けます。
このメニューコマンドはキーボードショートカットにも割り当て可能です。
直接開いた画面はfoobar2000より手前を保ち、背後のfoobar2000も操作できます。
ほかのアプリに対する常時最前面にはなりません。

本DSPが未登録または複数登録されている場合は、
安全のため設定を変更せず案内を表示します。

表示言語:
・自動（Windows）
・日本語
・English

設定画面下部から選択でき、設定、診断、ヘルプ、用語集、メニューへすぐ反映されます。
言語設定はDSPプリセットと別に保存されます。
ヘルプ、用語集、ライセンス、診断表示、確認メッセージも切り替わります。

画面レイアウト:
・基本設定と診断は、左列を上から下へ読んでから右列へ移る構成
・追加処理は、モダン／1バンド／3バンドの横3列カード表示
・共通の処理強度設定は追加処理タブの下段へ配置
・診断ページは上下の余白が均等になるよう調整

初期設定:
・［初期設定］を押すと確認ダイアログを表示
・［初期設定に戻す］のあと［適用］を押すと再生中のDSPへ反映
・キャンセル時は設定内容と［適用］状態を変更しない

適用操作:
・［適用］はプリセット選択、数値変更、設定チェック変更時だけ有効
・適用成功後は無効へ戻り、連続適用を防止

診断表示:
・2列レイアウトで各項目を正式名称表示
・Integratedラウドネス、True Peak、各減衰量も省略せず表示

表示テーマ:
・foobar2000本体のライト／ダーク設定へ自動追従
・設定画面、タブ、入力欄、ボタン、ツールチップ、用語集、
  項目ヘルプ、ライセンス・クレジット表示に対応
・画面を開いたままテーマを切り替えた場合もツールチップ配色を更新
・Windows表示倍率に合わせてツールチップの最大幅を調整
・高倍率で画面が作業領域を超える場合は、画面内へ収めてスクロール表示

標準ノーマライズ:
・ナチュラル -18
・パワーブースト -14
・リラックス -23
・ナイトセーフ -22

追加マスタリング処理:
・モダンブースト -9
・1バンド・アダプティブ -10
・3バンド・アダプティブ -10

追加マスタリング処理は、音色やダイナミクスにも影響します。

ユーザープリセット:
・現在の基本設定と追加処理設定を［名前を付けて保存］で保存
・［呼出］［上書き］［名前変更］［削除］に対応
・日本語／英語を含む1～64文字の名前を使用可能
・最大100件まで保存
・既存7プリセットは変更・削除不可
・foobar2000の設定内だけに保存し、外部送信しない

リアルタイム自動制御:
・過剰状態が0.75秒続くと自動安全補正
・補正上限は6 dB
・安全状態が3秒続くと補正をゆっくり解除
・状態は「正常／監視中／自動調整中／調整上限」で表示
・安全復帰後の現在の処理状態は「正常」に戻る
・未発動時は「この曲では未発動」と表示
・安全復帰後は「直近：発動理由（復帰済み）」と表示
・発動理由と実施した自動減衰量を診断へ表示

自動制御履歴:
・診断タブの［自動制御履歴］から開く
・実際に自動制御が発動した最新100曲を保存
・再生日時、曲名／アーティスト、プリセット、発動理由、
  最大自動減衰量、発動回数、調整上限、安全復帰を表示
・［履歴コピー］［選択削除］［すべて削除］に対応
・短い「監視中」だけの曲は履歴へ追加しない
・履歴は再起動後も保持

自動制御推移グラフ:
・診断タブの［推移グラフ］から開く
・現在の1曲についてShort-term、総ゲイン、自動減衰量、
  処理後True Peakを約1秒ごとに記録
・自動制御の発動位置を赤い縦線で表示
・曲変更時に自動リセットし、再起動後には保持しない
・描画はグラフ画面を開いている間だけ実行
・音声処理スレッドではグラフ用処理を行わない
