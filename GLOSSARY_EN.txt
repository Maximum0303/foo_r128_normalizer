R128 Real-time Loudness Normalizer v1.11.0
English Glossary

Current processing state
Normal, Monitoring, Auto-adjusting, or Adjustment limit. Monitoring is the
0.75-second confirmation period. After safe recovery, the state returns to
Normal. The last trigger reason and positive automatic attenuation amount are
shown separately.

EBU R128
A loudness-measurement method designed to make perceived levels more
consistent.

LUFS
Loudness Units relative to Full Scale. Values closer to 0 sound louder.

LU
Loudness Unit, used to express a loudness difference. 1 LU is numerically
equivalent to 1 dB.

Momentary loudness
Loudness measured over approximately 400 milliseconds.

Short-term loudness
Loudness measured over approximately three seconds.

Integrated loudness
Average loudness from the start of measurement.

Loudness range (LRA)
Estimated difference between quieter and louder parts of a track.

True Peak / dBTP
Estimated peak between digital samples and its unit of measurement.

Target loudness
The loudness level the processed output approaches.

Maximum R128 boost / attenuation
Limits the range over which normalization gain can move.

True Peak limiter look-ahead
How far the limiter anticipates peaks. More look-ahead adds latency.

True Peak limiter release
How quickly the limiter returns to normal gain after reducing a peak.

Startup analysis time
Initial measurement time used to stabilize gain decisions.

Silence guard / boost hold
Prevents silence and very quiet passages from being raised excessively.

Gain lock
Locks normalization gain after loudness stabilizes.

Compressor
Reduces sections that are too loud.

Soft clipper
Rounds sharp peaks to preserve loudness.

True Peak limiter
Final stage that keeps output below the selected True Peak ceiling.

Automatic safety control
Adds up to 6 dB of attenuation when processing becomes too strong.

Automatic-Control History
Stores up to 100 recent tracks where automatic control actually activated.
It records playback time, title and artist, preset, trigger reason, maximum
automatic attenuation, activation count, adjustment-limit status, and safe
recovery. A brief Monitoring state without Auto-adjusting is not recorded.

Modern Boost
Combines compression, soft clipping, and True Peak limiting.

1-Band Adaptive
Automatically adjusts Modern Processing strength from loudness and LRA.

3-Band Adaptive
Controls low, mid, and high bands independently.

Crossover frequencies
Approximate 3-Band Adaptive boundaries: 160 Hz and 4 kHz.

Loudness-matched A/B comparison
Matches levels before comparing processed and original audio.

Full-bypass comparison
Bypasses every process in this component when Loudness match is off.

Maximum True Peak
Highest processed True Peak measured in the track.

Maximum compressor / clipper / limiter
Greatest reduction applied by each processing stage in the track.

0 dBTP exceedance events
Count of events where processed True Peak exceeded 0 dBTP.

CPU load
Estimated processing load of this DSP.

Invalid-sample protection
Replaces NaN, infinite, or extreme input samples with safe values.

User presets
Save all current Basic and Processing settings under a custom name.
User presets can be loaded, overwritten, renamed, or deleted.
The seven built-in presets remain unchanged, and user presets are stored
separately in the foobar2000 configuration.
